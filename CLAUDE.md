# Project Development Rules

## Decision Making

- Handle routine technical decisions independently.
- Ask for approval only for significant business decisions.
- Explain business implications and provide recommendations.

## Development Rules

- Do not change existing business logic without approval.
- Preserve financial accuracy and auditability.
- Avoid unnecessary architectural changes.
- Never expose API keys or credentials.

## Testing

- Preserve existing regression tests.
- Run relevant tests after implementation.
- Report test failures and regression differences.

## Workflow

- Review existing code before making changes.
- Use Plan Mode for major architectural changes.
- Obtain approval before implementing major changes.
